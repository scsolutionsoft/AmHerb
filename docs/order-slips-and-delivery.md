# สลิป การสั่งซื้อ และการจัดส่งร้านสมาชิก

## ขั้นตอนซื้อ

1. เลือกสินค้าจากหน้าร้านสมาชิกแล้วเปิดตะกร้า
2. กรอกชื่อและโทรศัพท์ผู้รับ กดถัดไป
3. กรอกบ้านเลขที่/ห้อง เปิดป๊อปอัพเลือกจังหวัด → อำเภอ/เขต → ตำบล/แขวง → หมู่บ้าน/ชุมชน และตรวจรหัสไปรษณีย์ เลือกผู้ขนส่ง
4. ตรวจสอบที่อยู่ ส่วนลดหรือ Token แล้วสร้างใบสั่งซื้อ ยอดสุดท้ายและข้อมูลโอนแสดงก่อนชำระเงิน
5. โอนตามยอด แนบหรือถ่ายรูปสลิป แล้วกรอกเลขอ้างอิงธนาคาร กดส่งข้อมูลแจ้งโอน
6. ติดตามการตรวจรับเงินและการจัดส่งในใบสั่งซื้อ หน้าเว็บดึงสถานะทุก 5 วินาทีเมื่อแท็บเปิดอยู่

คำสั่งซื้อออนไลน์แบบโอนเงินต้องมีสลิปก่อนฝ่ายการเงินยืนยันรับเงิน ไม่รวมรายการชำระครบด้วย Token หรือใช้เครดิตบริษัทซึ่งมีขั้นตอนรับชำระของระบบเครดิตเดิม การแนบภาพไม่ใช่การยืนยันเงินเข้าบัญชีอัตโนมัติ

## POS และดูภาพ

- ใน POS เลือกโอนเงิน แนบรูปสลิปและเลขอ้างอิงได้พร้อมบันทึกการขาย หรือเปิดใบสั่งซื้อเพื่อแนบภายหลัง
- ปุ่มถ่ายรูปใช้กล้องหลังเมื่อเบราว์เซอร์/อุปกรณ์รองรับ หากไม่มีให้เลือกภาพจากเครื่อง
- รับภาพ JPEG, PNG, WebP สูงสุด 5 MB ต่อภาพ เก็บใน SQL Server แยกจากข้อมูลรายการชำระ เก็บประวัติภาพเดิมเมื่อส่งภาพใหม่
- ผู้ซื้อที่มีสิทธิ์ เจ้าของร้าน แคชเชียร์ของรายการ และเจ้าหน้าที่ที่มีสิทธิ์ดูออเดอร์/การเงินเปิดภาพในป๊อปอัพได้ URL ภาพตรวจสิทธิ์ทุกครั้งและไม่ให้แคช
- Admin > Payments คลิกเลขรายการเพื่อดูใบสั่งซื้อ/สลิปและแบบฟอร์มตรวจรับเงิน

## ร้านจัดส่งสินค้า

- MyStore > ตั้งค่าขนส่ง เปิด/ซ่อนตัวเลือกของร้าน หรือเพิ่มชื่อขนส่งใหม่ ค่าเริ่มต้น: ไปรษณีย์ไทย, Kerry/KEX, Flash Express, J&T Express
- ชื่อใช้ทะเบียนร่วม ป้องกันชื่อซ้ำด้วยคีย์มาตรฐานและ unique index; การเปิด/ซ่อนแยกร้าน ไม่เปลี่ยนร้านอื่น ค่าจัดส่งยังใช้กฎค่าจัดส่งกลาง
- MyStore > คำสั่งซื้อ: ดูสลิปและที่อยู่ รอยืนยันรับเงิน กดเริ่มเตรียมสินค้า บันทึกผู้ขนส่งจริงและเลขพัสดุ แล้วกดยืนยันส่งมอบ
- สถานะจัดส่งอัปเดตโดยร้าน ยังไม่ได้เชื่อม API บริษัทขนส่งเพื่อออกฉลากหรือรับสถานะพัสดุอัตโนมัติ

## ข้อมูลพื้นที่และฐานข้อมูล

ข้อมูลอ้างอิง: [Open Admin Data Thailand](https://github.com/open-admin-data/thailand-administrative-divisions), CC BY 4.0 (jakkrapongt, 2026) ปรับเป็นข้อมูลชื่อไทย รหัส ความสัมพันธ์ และรหัสไปรษณีย์ในไฟล์เดียว เก็บ commit และเงื่อนไขสิทธิ์ไว้ที่ `src/AmHerb.Web/Data/Addresses/SOURCE.txt` และ `LICENSE.txt` ไม่มีการส่งที่อยู่ลูกค้าให้แหล่งข้อมูลภายนอก

ข้อมูลนำเข้า 77 จังหวัด 928 อำเภอ/เขต 7,364 ตำบล/แขวง และ 79,818 รายการหมู่บ้าน/ชุมชน ไม่ใช่ฐานข้อมูลโครงการบ้าน/คอนโดทุกแห่ง มีช่องกรอกหมู่บ้าน อาคาร และรายละเอียดเพิ่มเติมเมื่อไม่พบในรายการ รหัสท้ายของหมู่บ้านไม่ได้แปลงเป็นเลขหมู่โดยอัตโนมัติ

Migration: `OrderSlipsAndDelivery` เพิ่มตารางสลิปและขนส่ง เพิ่มที่อยู่แบบแยกข้อมูลและขนส่งที่เลือกในออเดอร์ เก็บที่อยู่เดิมของรายการเก่าไว้ และกำหนดให้ออเดอร์ออนไลน์โอนเงินที่ยังรอชำระต้องมีสลิปก่อนยืนยัน
