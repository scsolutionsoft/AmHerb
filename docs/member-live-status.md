# หน้าสมาชิกและการติดตามสถานะ

- `/Member`: เลขใบสั่งซื้อเปิดหน้ารายละเอียดและชำระเงิน; ยอดขายแนะนำเปิดเฉพาะข้อมูลสถานะของผู้แนะนำ
- หน้าสมาชิก ใบสั่งซื้อ และรายละเอียดดาวน์ไลน์ดึงข้อมูลใหม่ทุก 5 วินาทีเมื่อเปิดแท็บอยู่ พร้อมเวลาอัปเดต ปุ่มอัปเดต และข้อความเมื่อขาดการเชื่อมต่อ ไม่ใช่การรับผลธนาคารแบบทันที
- การจองคำสั่งซื้อลด Token พร้อมใช้ทันทีและเพิ่มยอดจอง การยืนยันรับเงินตัดยอดจองครั้งเดียว การยกเลิกคืนยอดพร้อมใช้ ใช้ธุรกรรมและ ledger เดิม
- สมาชิกแนบหรือถ่ายรูปสลิปและแจ้งเลขอ้างอิงธนาคารในใบสั่งซื้อ สถานะเป็น “แจ้งโอนแล้ว · รอตรวจสอบ” ฝ่ายการเงินดูเลขอ้างอิงใน Admin > Payments และตรวจรับเงินก่อนยืนยันตามขั้นตอนเดิม ข้อมูลแจ้งโอนแยกจากเลขอ้างอิงที่ยืนยันแล้ว
- ดาวน์ไลน์เปิดดูชื่อ รหัส สถานะ ระดับ และสมาชิกที่แนะนำโดยตรงได้เฉพาะสายงานของผู้ใช้ ไม่มีข้อมูลติดต่อหรือกระเป๋าของผู้อื่น
- การรีเฟรชไม่เขียนทับช่องแบบฟอร์มที่กำลังกรอก และรักษาแท็บ/ผังที่เปิดอยู่

ก่อนใช้งานรุ่นนี้ให้อัปเดตฐานข้อมูลด้วย migration `MemberPaymentSubmission`:

```powershell
dotnet ef database update --project src/AmHerb.Web
```

ตั้งค่า `Payments:BankInstructions` เป็นข้อมูลบัญชีจริงของร้าน การรับเงินยังเป็นโอนธนาคารที่ฝ่ายการเงินตรวจสอบเอง ไม่มีการเชื่อม PromptPay/Card gateway เพิ่มในงานนี้

ขั้นตอนซื้อแบบ Wizard การเลือกที่อยู่ และการตั้งค่าขนส่ง: [คู่มือสลิปและจัดส่ง](order-slips-and-delivery.md)
