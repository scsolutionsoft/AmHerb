# เครดิตสมาชิกและลูกหนี้การค้า

เปิด `/Credit` จากเมนูพื้นที่สมาชิก หรือจากหน้าบัญชีเดบิต–เครดิต

## ขั้นตอนใช้งาน

1. ฝ่ายการเงิน / Admin / SuperAdmin เปิดบัญชีด้วยรหัสสมาชิก กำหนดวงเงิน ระยะเวลา 1–365 วัน (เริ่มต้น 30 วัน) ประเภทสมาชิกหรือมาสเตอร์ดีลเลอร์ และเหตุผลอนุมัติ
2. สมาชิกที่ได้รับสิทธิ์เลือก “ซื้อด้วยวงเงินเครดิตบริษัท” ในตะกร้าหน้าร้านบริษัท ระบบตรวจวงเงินและหนี้เกินกำหนดฝั่งเซิร์ฟเวอร์ภายในธุรกรรมเดียวกับการตัดสต๊อก
3. สมาชิกหรือฝ่ายการเงินแจ้งยอดโอน วันเวลา เลขอ้างอิงธนาคาร และแนบสลิปได้ สลิปเก็บในฐานข้อมูลและเข้าถึงได้เฉพาะเจ้าของบัญชีหรือฝ่ายการเงิน
4. ฝ่ายการเงินตรวจยอดเข้าบัญชีจริง แล้วอนุมัติหรือปฏิเสธ การแจ้งโอนอย่างเดียวยังไม่คืนวงเงิน
5. การอนุมัติตัดบิลตามวันครบกำหนดและเลขบิล รองรับจ่ายบางส่วนหรือหลายบิลในรายการเดียว และคืนวงเงินเท่ากับยอดที่ตัดหนี้สำเร็จ
6. ดูรายงานยอดคงค้าง วงเงินคงเหลือ หนี้เกินกำหนด อายุหนี้ ใบแจ้งยอดตามช่วงวัน และรายละเอียดตัดชำระรายใบรับโอน พร้อมป๊อบอัพพิมพ์/PDF

## เงื่อนไข

- วงเงินเป็นเครดิตซื้อสินค้าจากบริษัท ไม่ใช่ Token และไม่ใช่วงเงินของลูกค้ารายย่อยที่ซื้อผ่าน POS ของดีลเลอร์
- มาสเตอร์ดีลเลอร์เป็นประเภทบัญชีเครดิต ไม่ได้เพิ่มสิทธิ์ผู้ดูแลระบบ และไม่ได้เปลี่ยนแผนรางวัล
- บัญชีต้องได้รับอนุมัติเป็นรายคน ไม่มีการเปิดวงเงินอัตโนมัติให้สมาชิกเดิม
- เครดิตครบกำหนด ณ สิ้นวันไทยของวันที่ซื้อ + จำนวนวันเครดิต เงื่อนไขที่เปลี่ยนภายหลังใช้กับบิลใหม่
- หนี้เกินกำหนดหรือบัญชีถูกระงับจะซื้อด้วยเครดิตเพิ่มไม่ได้ แต่ยังแจ้งชำระหนี้ได้
- ลดวงเงินต่ำกว่าหนี้คงค้างไม่ได้ ใช้การระงับสิทธิ์แทน
- ไม่รับยอดโอนเกินหนี้และไม่ทำยอดเงินฝากล่วงหน้า ถ้ายอดหนี้ลดลงเพราะคืนสินค้าระหว่างรออนุมัติ ให้ปฏิเสธรายการแล้วตรวจสอบยอดใหม่
- เลขอ้างอิงธนาคารที่ยืนยันแล้วใช้ซ้ำไม่ได้ การยืนยันซ้ำไม่ลงบัญชีหรือตัดหนี้ซ้ำ
- ไม่มีการเชื่อมธนาคารหรือยืนยันสลิปอัตโนมัติ การอนุมัติหมายถึงเจ้าหน้าที่ตรวจยอดจริงแล้ว
- ซื้อเชื่อส่งเข้าสถานะเตรียมดำเนินการเพื่อจัดส่งได้ แต่ยังไม่ใช่การรับเงินสด และต้องปิดหนี้บิลนั้นก่อนยืนยันรางวัล Token ตามขั้นตอนเดิม

## บัญชีย่อย

| เหตุการณ์ | เดบิต | เครดิต |
|---|---|---|
| ซื้อด้วยเครดิต | 1100 ลูกหนี้การค้า | รายได้สินค้า / ค่าจัดส่ง / ภาษีตามคำสั่งซื้อ |
| รับโอนชำระหนี้ที่ตรวจสอบแล้ว | 1020 ธนาคาร | 1100 ลูกหนี้การค้า |
| คืนสินค้า | กลับรายการรายได้/ภาษีตามระบบเดิม | 1100 ลดหนี้ส่วนที่ค้าง แล้ว 1020 คืนเงินเฉพาะส่วนที่ชำระแล้ว |

ต้นทุนและสต๊อกลงบัญชีตามขั้นตอนขาย/คืนสินค้าเดิม ยอด Token ที่ใช้แลกยังใช้การจัดประเภทส่วนลดเดิม

ใบแจ้งยอดมีวันที่ลงบัญชีเป็นฐาน พร้อมยอดยกมา เดบิต เครดิต และยอดสิ้นงวด จึงไม่ย้อนวันที่รับโอนที่เพิ่งตรวจสอบในภายหลัง รายงานอายุหนี้แสดงยอดปัจจุบัน แยกยังไม่ครบกำหนด / 1–30 / 31–60 / 61–90 / มากกว่า 90 วัน

## การควบคุมและตรวจสอบ

ตาราง CreditAccounts, CreditInvoices, CreditReceipts, CreditAllocations เพิ่มโดย migration MemberTradeCredit โดยไม่ปรับรายการขายเดิม ธุรกรรม serializable และการล็อกบัญชีป้องกันใช้วงเงินเกินและอนุมัติรับเงินซ้ำ มี rowversion สำหรับแก้ไขวงเงิน ประวัติ audit และแจ้งเตือนเจ้าของบัญชี รายการตัดชำระและใบรับโอนที่ตรวจสอบแล้วแก้ไขหรือลบไม่ได้ทั้งใน EF และ SQL trigger

ทดสอบวงเงิน ยอดเกินกำหนด ระงับบัญชี จ่ายบางส่วน จ่ายครบ ใบอ้างอิงซ้ำ สิทธิ์เจ้าของสลิป ซื้อพร้อมกัน อนุมัติพร้อมกัน คืนสินค้าก่อน/หลังรับเงิน และการกระทบยอดบัญชี พร้อมทดสอบ workflow บน browser
